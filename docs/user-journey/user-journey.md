# User Journey 

## 1. Cel dokumentu

Celem dokumentu jest przedstawienie ścieżek użytkowników aplikacji Hungrycator podczas realizacji głównego celu biznesowego, jakim jest wspólne planowanie i wybór posiłków przez domowników.

Analiza uwzględnia kolejne etapy podróży użytkownika, punkty styku (Touchpoints) powiązane z makietami High-Fi, punkty bólu (Pain Points) oraz szanse rozwoju systemu (Opportunities) dla dwóch zdefiniowanych Person (opisanych w osobnym dokumencie):

* **Persona 1:** Anna Kowalska
* **Persona 2:** Marek Nowak

---

| 2. Wybór użytkownika | Marek wybiera siebie na pasku „Jesteś:”. | Pasek wyboru domownika `[Makieta: ...]` | Możliwość pomyłki przy wyborze użytkownika. | Czytelne oznaczenie aktywnego domownika. |
